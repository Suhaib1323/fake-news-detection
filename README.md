## 🚀 Project Overview

This project uses a supervised Machine Learning classification model trained on a Fake & Real News dataset to detect whether a news article is **REAL or FAKE**.

The system includes:

- Data preprocessing & text cleaning
- TF-IDF feature extraction
- Logistic Regression classification
- Model evaluation (Accuracy, Precision, Recall, F1-score)
- Model saving using Joblib
- Interactive Streamlit web application
- Suspicious keyword highlighting
- Prediction probability visualization
- Premium dark-themed UI design

## 🧠 Machine Learning Workflow

1. Data Cleaning  
2. Text Preprocessing

4. Train-Test Split
